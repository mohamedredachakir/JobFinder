# JobFinder Manuel Utilisateur

## Demarrage rapide
1. Copier .env.example vers .env
2. Ajouter les cles API
3. Lancer ./deploy.sh

## Modules
- Authentification
- Recherche d'offres
- Favoris
- Candidatures Kanban
- Alertes email
- Dashboard

## API
- Swagger: http://localhost:8080/swagger-ui/index.html
- OpenAPI: http://localhost:8080/v3/api-docs
